# 💰 Money Expenses Application

A modern, responsive web and mobile application for personal expense tracking, designed around a **radial expense hub** and an intuitive **12-month calendar breakdown**.

---

## 🎨 Key Features & Architecture

### 1. 🎯 Main Screen — Radial Expense Hub
* **Center Hub**: Shows the total amount of money spent for the current period/month (e.g. `$1,840` / `$2,500`), budget progress bar, and percentage used.
* **Radiating Category Spokes**: Connected via directional spokes / mind-map nodes radiating from the center circle (inspired by your drawing).
* **Top Left "Calendar" Button**: Quick one-click navigation to the 12-month calendar overview.
* **Quick Add Expense Modal**: Fast logging with instant budget updates.

### 2. 📅 Calendar Screen — 12-Month Expense Breakdown
* **Year View**: Organized as a clean 12-month grid (January to December).
* **Monthly Totals**: Displays the total sum spent in each month (e.g., *January: $300*, *November: $1,000*).
* **Category Breakdown Sub-labels**: Directly underneath each monthly total, shows a categorized itemized list of expenditures (e.g. `Grocery: $420`, `Rent: $350`, `Transport: $150`).

## 🖌️ 5 Design Styles Included

You can switch between all 5 designs with one click in the interactive prototype:

1. **Nordic Minimal**: Clean paper-white aesthetic with sage green accents, subtle borders, and calm typography.
2. **Dark Fintech**: Obsidian dark mode with glowing electric mint (`#00F59B`) and neon cyan accents (Revolut / Robinhood style).
3. **Neo-Brutalism**: Chunky 2.5px solid black borders, hard drop shadows (`6px 6px`), tactile pastel cards (yellow, coral, sky blue).
4. **Apple Glassmorphism**: Translucent frosted acrylic glass (`backdrop-blur`), soft ambient shadows, SF Pro feel, iOS gradients.
5. **Retro Cyber Terminal**: Dark graphite background, monospace font (`JetBrains Mono`), terminal green telemetry style.
